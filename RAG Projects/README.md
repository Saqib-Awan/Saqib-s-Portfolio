# RAG Projects

A collection of applied Retrieval-Augmented Generation (RAG) frameworks developed by Muhammad Saqib. The implementations range from agentic self-correcting pipelines and multi-modal vector search to knowledge graph traversal, financial tabular analytics, and automated RAG evaluation. Each project is self-contained with complete source code, evaluation metrics, and comprehensive documentation.

## Project Index

1. `Agentic RAG with LangGraph/` - Autonomous multi-step retrieval state graphs with conditional routing and dynamic search tools.
2. `Corrective RAG (CRAG) with Adaptive Search Fallback/` - Self-evaluating retrieval pipeline with real-time web search fallback for ambiguous queries.
3. `Enterprise Multilingual Policy and Compliance Q&A Engine/` - Hybrid Reciprocal Rank Fusion (BM25 and FAISS) with cross-encoder re-ranking across international corporate policies.
4. `Financial Report and SEC 10-K Comparative Analysis RAG/` - Table-aware extraction and multi-period comparative retrieval across corporate financial filings.
5. `GraphRAG - Knowledge Graph Augmented Retrieval Engine/` - Hybrid retrieval combining NetworkX / Neo4j knowledge graph traversal with dense vector search for multi-hop reasoning.
6. `Multi‑Modal RAG – Text + Image Understanding/` - Joint text and image semantic indexing for multimodal document query resolution.
7. `RAG Evaluation Pipeline with RAGAS/` - Automated evaluation framework measuring context precision, faithfulness, and answer relevance.
8. `Self-RAG - Dynamic Reflection and Citation Generator/` - Adaptive retrieval gating with critique tokens and sentence-level source citations.
9. `The Core Memory Bank (PDF Document Q&A)/` - Persistent vector memory for multi-document document retrieval and synthesis.
10. `The Financial Analyst – Natural Language to SQL with LLM/` - Structured natural language to SQL translation over enterprise databases.
11. `The YouTube Summarizer & Study Buddy/` - Video transcript chunking, semantic indexing, and automated study notes generation.

## Tech Stack

Python, LangChain, LangGraph, LlamaIndex, NetworkX, Neo4j, FAISS, ChromaDB, Sentence-Transformers, OpenAI API, Google Generative AI, RAGAS
