# LangChain Projects

A curated collection of LangChain and LLM applications and utilities developed by Muhammad Saqib. Each subproject is self-contained with its own code, dependencies, and documentation, covering retrieval-augmented question answering, automated SQL analytics agents, multimodal PDF inspection, structured data extraction, summarization, and audio transcription.

## Quick Start

- Refer to individual project README files for specific setup and configuration instructions.
- Prerequisites: Python 3.9+, virtual environment, and appropriate API credentials where required.
- Typical run command for Streamlit apps: `streamlit run app.py` within the respective project directory.

## Project Index

1. `Audio To Text Transcription/` - Whisper automatic speech recognition with LLM conversational post-processing.
2. `Autonomous SQL Data Analyst Agent with LangChain and SQLite/` - Text-to-SQL agent with schema introspection, query self-healing, and automated Plotly visualization.
3. `Basic PDF QA/` - RetrievalQA pipeline querying single PDF documents via in-memory vector storage.
4. `Blog Generation/` - Streamlit application generating long-form blog posts via local quantized Llama 2 models.
5. `Calories Health Advisor/` - Gemini Vision nutritional analyzer calculating caloric metrics from food imagery.
6. `Chat With Multiple Documents/` - Multi-PDF conversational Q&A system powered by Google Generative AI embeddings and FAISS.
7. `Codebasics FAQ Chatbot/` - Domain FAQ retrieval system utilizing Instructor embeddings and vector similarity search.
8. `Conversational Q&A Chatbot/` - Multi-turn conversational chatbot utilizing ChatOpenAI and conversation buffer memory.
9. `Invoice Data Extractor/` - Pydantic schema extraction pulling structured tabular JSON from raw invoice documents.
10. `LLM Generic App/` - End-to-end PDF processing pipeline with Pinecone vector database indexation.
11. `Multimodal Research Paper Assistant and Visual Diagram Inspector/` - Gemini Flash Vision paper assistant extracting architectural diagrams and LaTeX equations.
12. `News Research Tool/` - Real-time news article ingestion, chunking, and source-attributed question answering.
13. `Q&A Chatbot Using LLM/` - Single-turn completion chatbot answering open-domain queries.
14. `SQL Database QA/` - Enterprise MySQL inventory query pipeline using SQLDatabaseChain and few-shot examples.
15. `Text Summarization/` - Extractive and abstractive text summarization routines for long documents.
16. `Web Page Summarization/` - Dynamic web page scraper and summarizer leveraging stuff, map-reduce, and refine chains.
17. `WordPress Code Assistant/` - Domain-specific PHP and WordPress code generator with automatic syntax validation.

## Tech Stack

Python, LangChain, LangChain-Community, OpenAI API, Google Generative AI (Gemini), FAISS, ChromaDB, Pinecone, Streamlit, SQLite
