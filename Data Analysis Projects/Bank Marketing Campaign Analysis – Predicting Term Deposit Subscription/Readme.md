# Bank Marketing Campaign Analysis – Predicting Term Deposit Subscription

**Author:** Saqib   

## Overview

This project analyses a Portuguese bank's direct marketing campaigns (phone calls) to predict whether a client will subscribe to a term deposit. It uses demographic, campaign, and economic data to identify factors that drive conversions. The insights help optimise targeting, reduce call costs, and improve ROI.

## Dataset

- **Source:** UCI Bank Marketing Dataset (bank-additional.zip)  
- **Rows:** 41,188 contacts  
- **Columns:** age, job, marital, education, default, housing, loan, contact, month, duration, campaign, pdays, previous, poutcome, emp_var_rate, cons_price_idx, euribor3m, nr_employed, y (target)

## Visualisations Included

1. Target distribution (bar chart)  
2. Age distribution by subscription (histogram + KDE)  
3. Subscription rate by job category (horizontal bar)  
4. Subscription rate by marital status (bar chart)  
5. Subscription by contact month (line plot)  
6. Call duration vs subscription (box plot)  
7. Previous campaign outcome impact (bar chart)  
8. Correlation heatmap  
9. Feature importance (logistic regression coefficients)  
10. Confusion matrix  

## How to Run

1. Open the notebook in Google Colab.  
2. Run all cells sequentially.  
3. The dataset will be downloaded automatically from UCI.
