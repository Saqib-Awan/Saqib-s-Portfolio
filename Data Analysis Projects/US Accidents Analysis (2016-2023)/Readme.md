# US Accidents Analysis (2016-2023)

**Author:** Saqib   

## Overview

This project analyses traffic accident data from the US (2016-2023). It identifies peak hours, seasonal trends, hazardous weather conditions, and geographic hotspots. The insights help authorities improve road safety measures.

## Dataset

- **Source:** Kaggle – US Accidents (2016-2023)  
- **Rows:** ~2.5 million (sample used: 200,000)  
- **Columns:** Start_Time, Severity, Weather_Condition, Temperature, City, State, Latitude, Longitude

## Visualisations Included

1. Accidents by year  
2. Accidents by hour of day  
3. Top 10 cities with most accidents  
4. Severity distribution  
5. Weather condition impact (top 8)  
6. Temperature distribution  
7. Accidents by month (seasonal)  
8. Day of week vs severity (heatmap)  
9. Top 10 hazardous weather conditions  
10. Geographic scatter plot  

## How to Run

1. Open the notebook in Google Colab.  
2. Upload the `US_Accidents_Dec23.csv` file (download from Kaggle).  
3. Run all cells sequentially.
