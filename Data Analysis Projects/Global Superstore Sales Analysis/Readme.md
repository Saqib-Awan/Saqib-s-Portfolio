# Global Superstore Sales Analysis

**Author:** Saqib  

## Overview

This project performs a comprehensive exploratory data analysis on retail sales data from a global superstore. The analysis uncovers trends in sales and profit, identifies top products and loss‑making items, evaluates regional performance, and examines the impact of discounts. The notebook contains **10 professional visualisations** suitable for business presentations.

## Dataset

- **Source:** Global Superstore dataset (public, available on Kaggle or Plotly)
- **Records:** ~51,000 orders across 2011–2014
- **Key fields:** Sales, Profit, Discount, Order Date, Region, Category, Segment, Ship Mode

## Visualisations Included

1. Monthly sales and profit trend  
2. Top 10 most profitable products  
3. Sales distribution by region (box plot)  
4. Discount vs profit scatter plot  
5. Monthly sales heatmap by year  
6. Profit by customer segment  
7. Top 10 loss‑making products  
8. Correlation heatmap of numerical variables  
9. Subcategory sales treemap  
10. Shipping mode preference by region  

## Setup

- Python 3.9+ with pandas, matplotlib, seaborn, squarify
- Google Colab or local Jupyter

## How to Run

1. Open the notebook in Colab.
2. Run all cells sequentially.
3. The dataset will be loaded automatically from a public URL (or you can upload your own `global_superstore.csv`).
4. All visualisations will be displayed inline.

## Example Output (Insights)

- **Total Sales:** ~$12.6M  
- **Total Profit:** ~$1.5M  
- **Profit Margin:** 12%  
- **Best Region:** West  
- **Worst Product (loss):** Cubify Cube 3D Printer
