# AI Security and Guardrails Projects

Welcome to the **AI Security and Guardrails Projects** repository. This domain contains 11 enterprise-grade AI security, guardrail, and trustworthy AI engineering implementations designed to harden machine learning systems against adversarial attack, intellectual property theft, data leakage, and algorithmic bias.

## Domain Overview

This collection covers:
- Automated LLM red-teaming and prompt fuzzing harnesses (Tree of Attacks)
- Real-time prompt injection and jailbreak interception firewalls (Llama-Guard 3)
- Hallucination and factuality evaluation benchmark engines (NLI Entailment)
- Adversarial robustness and white-box evasion defenses (FGSM, PGD-20)
- Automated PII and PHI masking gateways (Presidio, HIPAA Safe Harbor)
- Differential privacy engines for deep learning (DP-SGD with PyTorch Opacus)
- Model stealing and membership inference attack detection suites
- Cryptographic watermarking and provenance tracking (C2PA standard)
- Automated algorithmic bias, fairness, and disparate impact auditing
- Neural network backdoor and Trojan detection suites (Neural Cleanse)
- Enterprise AI governance and compliance audit suites (EU AI Act, NIST AI RMF)
