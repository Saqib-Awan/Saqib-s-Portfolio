# Robotics and Embodied AI Projects

Welcome to the **Robotics and Embodied AI Projects** repository. This domain indexes 11 advanced physical AI, spatial intelligence, and robotic perception implementations spanning autonomous ground vehicles, aerial robotics, industrial manipulation, and reinforcement learning locomotion.

## Domain Overview

This collection covers key challenges in modern embodied AI:
- Simultaneous Localization and Mapping (SLAM) with ROS2 and Nav2
- Inverse kinematics and path planning with MoveIt2
- Drone trajectory optimization with minimum-snap polynomials
- Quadruped locomotion trained via massively parallel PPO in NVIDIA Isaac Sim
- Image-based visual servoing (IBVS) for industrial cobots
- 3D LiDAR point cloud semantic segmentation with PointNet++
- Simulation-to-real (Sim2Real) domain randomization pipelines
- Multi-agent warehouse fleet coordination with Conflict-Based Search (CBS)
- Error-State Extended Kalman Filter (ES-EKF) multi-sensor fusion
- Visual-inertial odometry (VIO) for GPS-denied environments
- ISO/TS 15066 compliant collaborative human-robot safety monitors
