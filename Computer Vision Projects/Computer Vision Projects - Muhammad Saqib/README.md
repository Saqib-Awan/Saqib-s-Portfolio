# Computer Vision Projects

A collection of applied computer vision projects by **Muhammad Saqib**, covering medical imaging, digital forensics, and real time safety detection. Each project is self contained with its own README, code, and sample results.

## Project Index

- `Brain Tumor Detection/` — MRI tumor classification using CNN, MLP, and VGG16
- `Deep Fake Video Detection/` — Detect AI manipulated videos with deep learning
- `Digital Image Tampering Detection/` — Image forensics for detecting edited images
- `Eye Diseases Detection/` — Classification of cataract, glaucoma, and diabetic retinopathy from retinal images
- `Fire Detection YOLOv8/` — Real time fire detection for safety monitoring

## Tech Stack

Python, OpenCV, TensorFlow/Keras, PyTorch, YOLOv8, VGG16, scikit-learn
