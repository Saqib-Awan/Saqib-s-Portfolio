# Computer Vision Projects

A collection of applied computer vision projects by Muhammad Saqib, covering real-time object tracking, automated license plate recognition, facial emotion analytics, industrial defect inspection, multimodal document analysis, medical imaging diagnostics, and digital forensics. Each project is self-contained with its own code, dependencies, and detailed documentation.

## Project Index

1. `Automated License Plate Recognition and Surveillance System/` - YOLOv8 vehicle and plate localization paired with PaddleOCR alphanumeric text recognition.
2. `Brain Tumor Detection/` - MRI tumor classification using deep convolutional neural networks and VGG16 transfer learning.
3. `Deep Fake Video Detection/` - Video frame forensics and deep learning models detecting AI-generated manipulations.
4. `Digital Image Tampering Detection/` - Error level analysis (ELA) and forensic inspection for manipulated images.
5. `Document Layout Analysis and Table Extraction Engine/` - LayoutLMv3 vision transformer segmenting page structures and extracting borderless tables to Markdown.
6. `Eye Diseases Detection/` - Multi-class retinal image classification covering diabetic retinopathy, glaucoma, and cataracts.
7. `Facial Emotion Recognition and Engagement Analytics System/` - MediaPipe FaceMesh combined with ResNet-50 for emotion classification and attention scoring.
8. `Fire Detection YOLOv8/` - Real-time fire and hazard detection for automated safety monitoring.
9. `Industrial Surface Defect Inspection with Grad-CAM Explainability/` - ResNet-50 quality inspection engine with Grad-CAM saliency heatmaps for manufacturing quality assurance.
10. `Medical Lung Disease and Pneumonia X-Ray Classifier/` - DenseNet-121 pulmonary abnormality detection with Monte Carlo uncertainty quantification.
11. `Real-Time Multiclass Object Tracking with ByteTrack and YOLOv8/` - High-frame-rate multi-object tracking and trajectory velocity estimation in dense urban traffic.

## Tech Stack

Python, PyTorch, Torchvision, Ultralytics YOLOv8, OpenCV, MediaPipe, PaddleOCR, LayoutLMv3, TensorFlow/Keras, Scikit-Learn, NumPy, Matplotlib
