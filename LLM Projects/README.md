# LLM Projects

A curated collection of Large Language Model (LLM) engineering projects developed by Muhammad Saqib. The repositories encompass autonomous multi-agent task swarms, enterprise security red-teaming guardrails, parameter-efficient fine-tuning (PEFT/LoRA), function-calling tool use, automated LLM-as-a-judge evaluation frameworks, and reasoning paradigms. Each project includes complete code, execution traces, and detailed technical documentation.

## Project Index

1. `Autonomous Multi-Agent Collaborative Task Execution Swarm/` - Hierarchical multi-agent system coordinating Product Manager, Architect, Coder, and QA roles with self-healing feedback loops.
2. `Chain‑of‑Thought & Self‑Consistency/` - Multi-path reasoning sampling and majority voting frameworks boosting complex problem-solving accuracy.
3. `Code Generation with Llama/` - Synthesizing production Python and system routines using open-weights CodeLlama and Llama 3 models.
4. `Conversational Memory with Summarization/` - Context window management combining buffer memory with progressive summarization.
5. `Enterprise LLM Security Guardrails and Red-Teaming Suite/` - Llama-Guard 3 and NeMo Guardrails interceptor blocking prompt injections, jailbreaks, and PII leakage.
6. `Fine‑tune FLAN-T5 on Instruction Data/` - Parameter-efficient instruction fine-tuning on domain-specific question-answering benchmarks.
7. `Function Calling Tool Use with Llama 3.1/` - Structured JSON schema function calling enabling models to invoke external calculators, APIs, and databases.
8. `LLM as a Judge – Automated Evaluation of Responses/` - Rubric-based automated evaluation of generated candidate responses using advanced frontier models.
9. `ReAct Agent (Reasoning + Acting)/` - Interleaved thought-action-observation reasoning loops querying external environment tools.
10. `Self-Ask with Web Search/` - Decomposition of complex queries into structured sub-questions resolved via dynamic web search calls.
11. `Semantic Search & Re‑ranking with Embeddings/` - Dense embedding retrieval combined with cross-encoder re-ranking for contextual document search.
12. `Structured Output Extraction/` - Pydantic-constrained schema parsing forcing language models to emit strictly validated JSON objects.
13. `Text‑to‑SQL with Llama/` - Natural language query compilation to relational database SQL dialects with automated schema validation.
