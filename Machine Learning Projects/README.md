# Machine Learning Projects

A collection of applied machine learning systems developed by Muhammad Saqib, covering explainable healthcare risk scoring, dynamic real estate valuation, logistics supply chain forecasting, customer lifetime value modeling, cyber intrusion classification, electrical grid load prediction, fraud detection, and predictive maintenance. Each project includes production-ready code, evaluation benchmarks, and full technical documentation.

## Project Index

1. `Bank Customer Churn Prediction/` - Gradient boosted decision trees identifying banking customer attrition drivers with SMOTE imbalance handling.
2. `Credit Card Fraud Detection/` - Anomaly detection and cost-sensitive classification on highly imbalanced financial transaction streams.
3. `Customer Lifetime Value and Churn Propensity Engine/` - Probabilistic BG/NBD and Gamma-Gamma CLV models combined with RFM customer segmentation.
4. `Dynamic Real Estate Valuation and Investment ROI Simulator/` - LightGBM hedonic property valuation with geospatial amenity distance modeling and 10-year cashflow projections.
5. `Employee Flight Risk and Talent Retention Optimizer/` - Supervised churn modeling with SHAP feature attribution to prescribe proactive retention interventions.
6. `Energy Grid Load and Renewable Power Forecasting Engine/` - Multivariate Prophet and XGBoost ensemble forecasting hourly megawatt electricity demand.
7. `Explainable Healthcare Patient Readmission Risk Predictor/` - Clinical risk scoring using XGBoost and SHAP TreeExplainer for 30-day hospital readmission prevention.
8. `House Price Prediction (Regression)/` - Regularized regression and tree ensembles predicting residential property sales prices.
9. `Network Cyber Intrusion Detection System/` - High-throughput network packet classification and PCA anomaly clustering for real-time attack mitigation.
10. `Predictive Maintenance – Machine Failure Classification/` - Multi-class industrial sensor telemetry classification preventing mechanical downtime.
11. `Supply Chain Delivery Delay Risk and ETA Prediction Engine/` - CatBoost logistics duration regression modeling weather and traffic hazards for accurate ETAs.

## Tech Stack

Python, Scikit-Learn, XGBoost, LightGBM, CatBoost, SHAP, Prophet, Lifetimes, Pandas, NumPy, Matplotlib
