# Full-Stack AI Applications

A curated collection of full-stack artificial intelligence and machine learning applications developed by Muhammad Saqib. Each project integrates a modern web user interface (Streamlit / FastAPI / React) with production AI backends, encompassing legal contract risk auditing, real-time voice consultations, natural-language executive business intelligence, automated code reviews, generative e-commerce creative studios, personalized Socratic learning tutors, quantitative portfolio optimizers, multilingual brand monitoring, ATS resume matchers with mock technical interviews, automated real estate deal underwriters, and meeting action trackers.

## Project Index

1. `AI Financial Portfolio Optimization and Algorithmic Strategy Studio/` - Modern portfolio theory backtester solving Markowitz efficient frontiers and Black-Litterman allocations.
2. `AI-Driven Meeting Intelligence and Action Item Tracker/` - Speaker diarization and audio transcript synthesis with automated Jira and Slack task creation.
3. `AI-Powered Code Reviewer and Security Vulnerability Scanner/` - Git diff inspection tool identifying OWASP CWE security vulnerabilities and generating unit tests.
4. `Automated Real Estate Market Deal Finder and Investment Underwriter/` - Automated pro-forma investment calculator evaluating cap rates, DSCR coverage, and renovation budgets.
5. `Enterprise AI Contract Intelligence & Risk Auditing Platform/` - Document intelligence platform extracting clauses, flagging unlimited liability exposures, and generating redlines.
6. `Generative E-Commerce Product Studio and Copy Optimization Engine/` - Virtual product photography staging with background alpha matting and conversion-optimized copy generation.
7. `Intelligent Business Intelligence & Executive Dashboard Studio/` - Natural-language to SQL data studio with automated Plotly figures and Z-score outlier detection.
8. `Intelligent Resume Matcher and Interview Simulation Engine/` - ATS resume keyword and vector matcher with interactive technical interview simulations.
9. `Multilingual Customer Sentiment and Brand Reputation Monitor/` - XLM-RoBERTa social media monitor evaluating brand affinity across 12 languages with PR crisis alerting.
10. `Personalized AI Learning Tutor and Adaptive Quiz Generator/` - Socratic tutoring application using Bayesian Knowledge Tracing to generate mastery-level practice problems.
11. `Real-Time Multimodal Voice AI Health Consultation Assistant/` - Low-latency voice consultation loop coupling Whisper speech recognition with Kokoro audio synthesis.

## Tech Stack
