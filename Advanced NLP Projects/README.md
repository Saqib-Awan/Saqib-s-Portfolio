# Advanced NLP Projects

A comprehensive collection of natural language processing architectures developed by Muhammad Saqib, spanning deep transformer models, biomedical named entity recognition, abstractive cross-document summarization, prompt injection detection, multilingual threat moderation, toxic comment classification, and text attribution. Each project provides complete source code, experimental notebooks or web applications, and extensive documentation.

## Project Index

1. `Advanced_Human_vs_AI_Text_Classifier_using_NLP_and_BERT/` - Transformer-based classification distinguishing human authorship from AI-generated prose.
2. `Advanced_Mental_Health_Sentiment_Analysis_NLP_Project/` - Multi-class emotional affect and mental wellbeing sentiment analysis from unstructured text.
3. `Advanced_Resume_Screening_System_using_NLP_and_ML/` - Automated CV parsing, skill extraction, and candidate-job matching engine.
4. `Advanced_Text_Origin_Classifier_NLP/` - Stylometric and syntactic modeling for text origin and genre identification.
5. `Clinical and Biomedical Entity Extraction and Relation Linking System/` - BioBERT token classification and UMLS knowledge base linking for clinical EHR records.
6. `Fact vs. Fabrication – Multi‑Genre Disinformation Detector/` - Deep learning classification detecting synthetic disinformation and altered news reporting.
7. `Financial_News_Sentiment_Classification_using_NLP_and_ML/` - Domain-adapted sentiment analysis scoring market news for algorithmic trading insights.
8. `Identity Shield – Multilingual Hate Speech & Threat Moderator/` - Cross-lingual transformer guardrail moderating online hate speech and toxic intent.
9. `Instruction Hierarchy (Prompt Injection) Classifier/` - Adversarial security classifier detecting indirect prompt injection and jailbreak payloads in LLM inputs.
10. `Jigsaw Toxic Comment Classifier/` - Multi-label classification identifying online toxicity, severe insults, and threats.
11. `Multi-Document Abstractive Summarization and Factuality Checker/` - BART-Large cross-document abstractive synthesis with FactCC NLI factual consistency auditing.
12. `Named Entity Recognition (NER) with Transformer (BERT)/` - Fine-tuned BERT token classifier extracting entities across CoNLL benchmark data.
13. `PubMedQA – Biomedical Question Answering/` - Domain-specific biomedical question answering utilizing scientific literature from PubMed.
